    32→## 1. Vision & Philosophy
    33→
    34→### 1.1 The Mission
    35→
    36→> **दुनिया का सबसे best educational platform बनाना — जहाँ कोई भी learner, किसी भी stage पर, किसी भी goal के लिए, सही depth में सीख सके।**
    37→
    38→A unified learning ecosystem where:
    39→- A Class 8 student can prepare for school + Olympiad + NEET Foundation simultaneously.
    40→- A Class 12 student can prepare for boards + NEET/JEE simultaneously.
    41→- A graduate can prepare for multiple competitive exams (RRB + SSC + Police) through ONE combined course — not three separate ones.
    42→- A college student can learn their degree curriculum + placement prep.
    43→- An ITI student can learn their trade + workshop skills.
    44→- Anyone can learn a skill (coding, Excel, digital marketing) anytime.
    45→- Everyone benefits from GK & Current Affairs, personalized to their exam level.
    46→- Books solutions serve as SEO entry points and reference.
    47→
    48→### 1.2 Core Philosophy
    49→
    50→| Principle | Meaning |
    51→|---|---|
    52→| **Knowledge ≠ Curriculum ≠ Exam ≠ Course** | Four separate layers. Knowledge is universal. Curriculum maps knowledge to a class. Exam maps knowledge to a test. Course is a generated path. Never mix them. |
    53→| **W3Schools Model Platform-Wide** | ALL content is freely browsable without login. Enrollment is for structured learning + progress tracking + personalization — NOT for access to content. |
    54→| **One Canonical Entity, Multiple Experiences** | A Concept (e.g., Photosynthesis) is ONE record. It powers: concept page, GK collection, quiz, compare entry, combined course — all from the same data. |
    55→| **Combined Course is the Killer Feature** | Students with multiple goals get ONE optimized path, not multiple separate courses. Two modes: depth-merge (school) + syllabus-merge (coaching). |
    56→| **Don't Teach Me Twice** | If a student mastered a concept for one goal, the system skips it for another goal. Mastery is portable across goals. |
    57→| **AI as Orchestration, Not Authority** | Human experts define canonical knowledge. AI assists with explanations, questions, personalization, tutoring. AI never auto-publishes canonical content. |
    58→| **Mobile-First, Always** | India learns on phones. Every page, every component, every interaction must be designed mobile-first. |
    59→| **Free Forever (For Now)** | All content free. No payment. Enrollment is free. Monetization comes later. |
    60→
    61→### 1.3 What Makes This Next-Gen & Unique
    62→
    63→1. **Combined Course Engine** — No competitor does this. Multiple exams → one optimized path.
    64→2. **Cross-Segment Pathways** — Class 8 → NEET Foundation → NEET → Doctor career. One continuous journey.
    65→3. **Depth-Layered Content** — Same concept taught at different depths based on goal. No duplicate content.
    66→4. **Unified Chat** — One chat system for doubts, AI tutoring, live classes, QNA. Not fragmented.
    67→5. **W3Schools-Style Free Access** — Browse everything free. Enrollment adds structure, not access.
    68→6. **AI Study Companion** — Knows your progress, weak areas, learning style. Personal AI tutor.
    69→7. **Knowledge Graph Navigation** — Visual concept maps, explore by connections.
    70→8. **Exam-Centric GK** — GK personalized to your exam level (RRB basic vs UPSC deep).

   104→### 2.3 Why Supabase Direct (No Prisma)?
   105→
   106→- **RLS (Row Level Security):** Enforce content visibility at DB level. Free users can't access paid content even via API leaks.
   107→- **Supabase Auth:** Built-in, shared across all segments.
   108→- **Supabase Realtime:** Live chat, live class updates, real-time progress.
   109→- **Supabase Storage:** Videos, images, PDFs, PPTs.
   110→- **Edge Functions:** Combined course engine, AI orchestration, spaced repetition — Deno functions.
   111→- **No ORM overhead:** Direct SQL where needed, typed client via `supabase-js`.
   112→

   115→| Component | Where |
   116→|---|---|
   117→| Frontend (Next.js app) | Vercel (free subdomain → custom domain later) |
   118→| Database + Auth + Storage | Supabase (free tier) |

   120→| AI inference | z-ai-web-dev-sdk (backend) |
   121→| Media (videos/images) | Supabase Storage (start) → Cloudflare R2 (when scale demands) |

   185→### 3.3 Combined Course Applicability (Important)
   186→
   187→Combined course is the killer feature, but NOT every segment needs it. Here's the clear rule:
   188→
   189→| Segment | Combined Course? | Mode | Why / Why Not |
   190→|---|---|---|---|
   191→| **School** | ✅ OPTIONAL | Depth-merge (foundation) + Syllabus-merge (scholarship) | Class 6–10 + NEET Foundation + NTSE share ~same syllabus |
   192→| **Senior** | ✅ OPTIONAL | Hybrid-merge (board + entrance) | Class 11–12 board + NEET/JEE share ~same NCERT |
   193→| **Coaching** | ✅ OPTIONAL | Syllabus-merge (multi-exam) | RRB + SSC + Police — different syllabi, dedupe common |
   194→| **GK** | ✅ Exam-centric personalization | (not "combined course" but personalized per exam) | Same GK, different depth per exam level |
   195→| **College** | ❌ NO | Per-semester path only | Each degree/semester is distinct; no overlap to merge |
   196→| **ITI** | ❌ NO | Trade-based path only | Each trade is distinct; no overlap to merge |
   197→| **Skills** | ❌ NO | Skill tracks / roadmaps only | Each skill is independent; no overlap to merge |
   198→
   199→**Rule:** If a segment's goals share significant syllabus overlap (like School foundation/scholarship, Senior board/entrance, Coaching multi-exam), combined course applies. If goals are disjoint (College semesters, ITI trades, individual skills), no combined course.

   289→## 5. Segments Deep-Dive
   290→
   291→### 5.1 School (Class 6–10)
   292→
   293→**Audience:** Class 6–10 students across boards (CBSE, ICSE, State boards like MP Board).
   294→
   295→**Note on Class 1–5:** Class 1–5 is intentionally excluded from this platform. Young children (ages 6–10) need kids-friendly gamification, animations, voice-led interactions, and a completely different UX paradigm. That is a separate future product, not part of Niodemy.
   296→
   297→**Content Model:**
   298→- Organized by: Board → Class (6–10) → Subject → Chapter → Concept → Lesson
   299→- Each class has its own complete curriculum design (user's specific requirement: "हर class के लिए पूरा system design")
   300→- Board-specific content (CBSE Class 8 Science ≠ MP Board Class 8 Science in structure, though concepts overlap)
   301→
   302→**Goals a student can have (combined course is OPTIONAL):**
   303→- **Basic school study only** — just Class 6–10 board curriculum (no combined course)
   304→- **+ NEET/JEE Foundation** — NCERT taught deeper (depth-merge)
   305→- **+ Scholarship** (NTSE, NMMS, KVPY, Olympiads) — scholarship syllabus ≈ class syllabus (syllabus-merge)
   306→- **+ Any combination** — e.g., Class 8 CBSE + NEET Foundation + NTSE
   307→
   308→**Combined Course Mode (Optional):**
   309→- **Depth-merge** for foundation goals (same NCERT, deeper depth)
   310→- **Syllabus-merge** for scholarship goals (scholarship syllabus ≈ class syllabus, dedupe common concepts)
   311→- Both can combine: Class 8 CBSE + NEET Foundation + NTSE → one optimized path
   312→- User can choose to NOT use combined course — just browse class content sequentially
   313→
   314→**Example:**
   315→```
   316→Student: Class 8 CBSE + NEET Foundation + NTSE Scholarship
   317→
   318→All three map to ~same Class 8 concept set:
   319→  - CBSE Class 8 Science: 40 concepts at depth L2
   320→  - NEET Foundation Class 8: same 40 concepts at depth L3 (+ 5 bridging concepts)
   321→  - NTSE Class 8: same 40 concepts at depth L2 (+ 10 aptitude concepts)
   322→
   323→Combined course:
   324→  - 40 common concepts at depth L3 (max)
   325→  - + 5 NEET bridging concepts at L3
   326→  - + 10 NTSE aptitude concepts at L2
   327→  - Total: 55 concepts, one path, covers all three goals
   328→```
   329→
   330→**Class Transition:**
   331→- When student moves Class 8 → Class 9, system:
   332→  1. Loads Class 9 curriculum
   333→  2. Checks which Class 9 concepts student already mastered (from prior learning)
   334→  3. Skips mastered, focuses on new
   335→  4. "Don't teach me twice" applied across classes
   336→
   337→**Key Principle:** Class 8 content and Class 11 content do NOT merge. Each class is its own bubble. Combined course works WITHIN a class (depth-merge for foundation + syllabus-merge for scholarship), not across classes.
   338→
   339→### 5.2 Senior (Class 11–12 + Entrance Exams)
   340→
   341→**Audience:** Class 11–12 students across streams (Science-Bio, Science-Math, Commerce, Arts) who are ALSO preparing for entrance exams (NEET, JEE Main, JEE Advanced, CUET) alongside their board exams.
   342→
   343→**Why Senior is a separate segment (not part of School):**
   344→Class 11–12 + NEET/JEE is fundamentally different from Class 6–10 + Olympiad:
   345→1. **Dual intense goals:** Board exam (detailed written answers) + Entrance exam (speed MCQs) — both high-stakes.
   346→2. **Same syllabus, different demands:** NEET/JEE syllabus = NCERT Class 11–12 syllabus. Same concepts, but NEET needs DEPTH + SPEED + PYQ practice, while board needs DETAILED QNA + long-form answers.
   347→3. **Different practice modes:** Board = long-answer writing practice; NEET = timed MCQ drills (180 Qs in 180 min).
   348→4. **Foundation → Senior continuity:** Class 8 NEET Foundation student → Class 11 Senior (NEET track). Mastery carries over ("don't teach me twice").
   349→5. **Allen Kota model:** NCERT taught at entrance-exam depth, not separate advanced content.
   350→
   351→**Content Model:**
   352→- Organized by: Board → Class (11/12) → Stream → Subject → Chapter → Concept → Lesson
   353→- Each concept has BOTH board-level depth (L2–L3) AND entrance-level depth (L3–L4)
   354→- Question types for BOTH formats:
   355→  - Board: long-form, short-form, diagram-based, source-based
   356→  - Entrance: MCQ (single correct), MCQ (multiple correct), assertion-reason, numerical, matching
   357→
   358→**Goals a student can have:**
   359→- Class 11/12 board exam (stream-specific)
   360→- NEET (if Science-Bio stream)
   361→- JEE Main / JEE Advanced (if Science-Math stream)
   362→- CUET (for central university admission)
   363→- State CET / other entrance
   364→
   365→**Combined Course Mode: Hybrid-Merge (the third mode)**
   366→
   367→Student: Class 12 CBSE (Science-Bio) + NEET
   368→- **Syllabus:** Same NCERT Biology concepts. NEET may add a few extension concepts.
   369→- **Depth:** max(board_depth, neet_depth) = neet_depth (L3–L4).
   370→- **Practice formats:** Board QNA (long-form) + NEET MCQ (timed) + NEET PYQs + Board PYQs.
   371→- **Speed dimension:** NEET needs 180 questions in 180 minutes → timed speed drills.
   372→- **Result:** ONE combined course that prepares for BOTH board + NEET simultaneously.
   373→
   374→```
   375→Combined Class 12 + NEET course =
   376→  Concepts (depth = NEET level)
   377→  + Board QNA practice (for written exam)
   378→  + NEET MCQ practice (for entrance)
   379→  + NEET PYQs (last 10 years)
   380→  + Board PYQs (last 10 years)
   381→  + Speed drills (timed MCQ sets)
   382→  + Daily plan balancing: concept learning + board practice + NEET practice
   383→```
   384→
   385→**The Pitch:** "आपको board + NEET दोनों की तैयारी एक ही course में। Board के लिए detailed answers, NEET के लिए speed MCQs — सब cover।"
   386→
   387→**Transition: School → Senior:**
   388→- Class 10 student (with NEET Foundation goal) → Class 11 Senior (NEET track)
   389→- System: loads Class 11 curriculum, checks mastery from Class 8–10 foundation, skips mastered, deepens to NEET level.
   390→- Foundation mastery → Senior credit. No re-learning.
   391→
   392→**Transition: Senior → Coaching (droppers):**
   393→- Class 12 student didn't crack NEET → takes a drop year → joins Coaching segment

   471→

   475→- Organized by: Skill Track → Tutorial Module → Lesson → Example → Exercise
   476→- Tutorials are browsable free (W3Schools model)
   477→- "Try it yourself" interactive examples where applicable (coding, Excel)
   478→- Exercises after each tutorial
   479→- Skill track / roadmap (e.g., "Become a Web Developer" = HTML → CSS → JS → React → Projects)

   481→**Skills Decision: Same Platform (Final)**
   482→
   483→**Rationale:**
   484→1. **Shared backbone:** One account, one learner profile, one knowledge graph. A college student can learn a skill alongside their degree.
   485→2. **W3Schools tutorials model fits:** Skills content is tutorial-based — same as the platform-wide free browsing model.
   486→3. **Cross-segment value:** A B.Tech student learning C programming in college can also do the "Skills: C Programming" track. Same content, different context.
   487→4. **Lower infrastructure cost:** One deployment, one DB, one auth.
   488→5. **Future extraction possible:** If Skills grows large (1000+ courses, heavy video), it can be extracted into a separate app using the same Supabase backend. Architecture supports this (clean route group, separate content tables, API isolation).
   489→
   490→**Why NOT separate like competitors (Seekho, etc.):**
   491→- Competitors separate because their core is different (Seekho = entertainment-style short videos, not structured learning).
   492→- Our model is structured learning. Skills fits naturally as a segment.
   493→- Separate app = separate account, separate progress, lost cross-segment value.
   494→- "Extract, don't pre-split" — start unified, split only when scale demands.
   495→
   496→**W3Schools Tutorials Model (Platform-Wide):**
   497→- This model applies to ALL segments, not just Skills.
   498→- All content browsable free (concepts, tutorials, questions, quizzes, mock tests).
   499→- Enrollment adds: structured path + progress tracking + personalization + AI tutor.

   508→- **Step 2: Practice (on demand)** — MCQs, Quizzes, QNA, MockTests accessible when user wants to practice

   512→```

   515→├── /gk/[category]/               → Category page (polity, economy, science, etc.) — content + practice links
   516→├── /gk/article/[slug]/           → Article page (indexable, content-first)

   518→│   ├── MCQs                       → Exam-wise subject MCQs
   519→│   ├── Quiz                       → Exam-wise quizzes
   520→│   ├── QNA                        → Exam-wise QNA
   521→│   └── MockTest                   → Exam-wise mock tests

   526→- RRB Group D aspirant: basic GK, high-level facts
   527→- SSC CGL aspirant: medium depth GK
   528→- UPSC aspirant: deep analytical GK
   529→- Same event, different depth presentations — powered by the same underlying data
   530→- User sees GK filtered/recommended for their enrolled exam(s)
   531→
   532→**GK is NOT a Subject — It's a Collection Layer:**
   533→- Questions have a `subject` (Biology, Polity, etc.) and a `gk_relevance` field (None/General/High)
   534→- GK pages are dynamic collections: `/gk/polity/` = all polity questions where gk_relevance ≠ None

   540→- GK feeds into School (age-appropriate current affairs)

   588→## 6. Content Access Model (W3Schools-Style)
   589→
   590→### 6.1 The Principle
   591→
   592→> **ALL content is freely browsable without login. Enrollment adds structure and tracking, NOT access.**
   593→
   594→This is the W3Schools model applied platform-wide:
   595→- W3Schools: You can read every tutorial, try every example, without an account. Account = progress tracking + exercises + certificates.
   596→- SnapZila Academy: You can read every concept, attempt every question, view every solution, without an account. Enrollment = combined course + progress tracking + personalization + AI tutor + daily plan.
   597→
   598→### 6.2 What's Free (No Login)
   599→
   600→| Content Type | Free? |
   601→|---|---|
   602→| Concept pages | ✅ Yes |
   603→| Lessons / Tutorials | ✅ Yes |
   604→| Chapters | ✅ Yes |
   605→| MCQs / Questions | ✅ Yes (attempt + view answer) |
   606→| Quizzes | ✅ Yes |
   607→| Mock Tests | ✅ Yes |
   608→| PYQs (Previous Year Questions) | ✅ Yes |
   609→| GK Articles | ✅ Yes |
   610→| Book Solutions (Atlas) | ✅ Yes |
   611→| QNA / Forum | ✅ Yes (read; posting requires login) |
   612→| Live Classes | ✅ Yes (watch; chat requires login) |
   613→
   614→### 6.3 What Requires Login (Enrollment)
   615→
   616→| Feature | Requires Login? | Requires Enrollment? |
   617→|---|---|---|
   618→| Combined Course generation | ✅ | ✅ |
   619→| Progress tracking | ✅ | ✅ |
   620→| Daily plan / personalized schedule | ✅ | ✅ |
   621→| Mastery tracking | ✅ | ✅ |
   622→| Bookmarks | ✅ | ❌ (login only) |
   623→| Notes | ✅ | ❌ (login only) |
   624→| AI Tutor chat | ✅ | ❌ (login only) |
   625→| Doubt chat in chapters | ✅ | ❌ (login only) |
   626→| QNA posting | ✅ | ❌ (login only) |
   627→| Live class chat | ✅ | ❌ (login only) |
   628→
   629→### 6.4 SEO Strategy
   630→
   631→| SEO Level | Content | Indexable? |
   632→|---|---|---|
   633→| Level 1 — MUST INDEX | Concept pages, GK articles, Atlas solutions, exam detail pages, tutorials, chapter pages, PYQ collections | ✅ |
   634→| Level 2 — SELECTIVELY INDEX | High-value collections (e.g., "SSC CGL Polity MCQs") | ✅ (only when genuinely differentiated) |
   635→| Level 3 — DON'T INDEX | Personalized pages (/my/*), practice sessions, quiz attempts, bookmarks | ❌ |
   636→| Level 4 — DEFINITELY DON'T INDEX | Combinatorial junk (exam × subject × difficulty × language × user) | ❌ |
   637→
   638→**Canonical Page Principle:** ONE canonical page per concept (e.g., `/concept/photosynthesis/`). Multiple presentation views (School view, Coaching view, GK view) use the same canonical URL with different UI — NOT duplicate pages.

  1108→## 8. Combined Course Engine
  1109→
  1110→### 8.1 Three Modes
  1111→
  1112→| Mode | Segment | What It Does | Example |
  1113→|---|---|---|---|
  1114→| **Depth-Merge** | School | Same class, same concepts, deeper depth for foundation goals | Class 8 CBSE + Class 8 NEET Foundation = same NCERT, taught deeper |
  1115→| **Hybrid-Merge** | Senior | Same syllabus (board + entrance), merge depth + practice formats + speed + PYQs | Class 12 CBSE Bio + NEET = one course, board QNA + NEET MCQ + speed drills |
  1116→| **Syllabus-Merge** | Coaching | Different exams, different syllabi, union + dedupe | RRB Group D + SSC GD + MP Police = one combined course |
  1117→
  1118→### 8.2 Depth-Merge Algorithm (School)
  1119→
  1120→```typescript
  1121→// For student with goals: [Class 8 CBSE, Class 8 NEET Foundation]
  1122→// Both map to same class level (8), so same concept set, different depths
  1123→
  1124→async function depthMergeCombinedCourse(userId: string, goals: Goal[]) {
  1125→  // 1. Get all curriculum_concepts for all goals (same class)
  1126→  const curriculumIds = goals.map(g => g.curriculum_id);
  1127→  const { data: concepts } = await supabase
  1128→    .from('education.curriculum_concepts')
  1129→    .select('concept_id, depth_required, importance, chapter_name, order_index')
  1130→    .in('curriculum_id', curriculumIds);
  1131→
  1132→  // 2. Merge: same concept → take MAX depth
  1133→  const mergedConcepts = mergeByMaxDepth(concepts);
  1134→
  1135→  // 3. Subtract already-mastered
  1136→  const { data: mastered } = await supabase
  1137→    .from('learning.progress')
  1138→    .select('concept_id')
  1139→    .eq('user_id', userId)
  1140→    .gte('mastery', 80);
  1141→  const pending = subtractMastered(mergedConcepts, mastered);
  1142→
  1143→  // 4. Add prerequisites recursively
  1144→  const withPrereqs = await addPrerequisites(pending);
  1145→
  1146→  // 5. Sort by chapter order (within same class, order matters)
  1147→  const sorted = sortByChapterOrder(withPrereqs);
  1148→
  1149→  // 6. Schedule into daily plan
  1150→  const dailyPlan = scheduleDaily(sorted, userId);
  1151→
  1152→  // 7. Cache as learning_path
  1153→  await saveLearningPath(userId, sorted, dailyPlan);
  1154→
  1155→  return { concepts: sorted, dailyPlan };
  1156→}
  1157→```
  1158→
  1159→### 8.3 Hybrid-Merge Algorithm (Senior — Class 11–12 + Entrance)
  1160→
  1161→```typescript
  1162→// For student with goals: [Class 12 CBSE Science-Bio, NEET]
  1163→// Same NCERT syllabus, but NEET needs deeper depth + speed + PYQs
  1164→// Board needs detailed QNA. Merge ALL practice dimensions.
  1165→
  1166→async function hybridMergeCombinedCourse(userId: string, goals: Goal[]) {
  1167→  const curriculumId = goals.find(g => g.type === 'class')?.curriculum_id;
  1168→  const entranceExamIds = goals.filter(g => g.type === 'exam').map(g => g.exam_id);
  1169→
  1170→  // 1. Get curriculum concepts (board syllabus)
  1171→  const { data: boardConcepts } = await supabase
  1172→    .from('education.curriculum_concepts')
  1173→    .select('concept_id, depth_required, importance, chapter_name, order_index')
  1174→    .eq('curriculum_id', curriculumId);
  1175→
  1176→  // 2. Get entrance exam concepts (NEET/JEE syllabus — mostly same NCERT + extensions)
  1177→  const { data: entranceConcepts } = await supabase
  1178→    .from('exams.exam_concepts')
  1179→    .select('concept_id, depth_required, importance, subject, exam_id')
  1180→    .in('exam_id', entranceExamIds);
  1181→
  1182→  // 3. Merge concepts: union (board ∪ entrance), depth = MAX per concept
  1183→  const mergedConcepts = mergeByMaxDepthAcrossBoardAndEntrance(boardConcepts, entranceConcepts);
  1184→  // Result: same NCERT concepts at NEET depth + any extra entrance-only concepts
  1185→
  1186→  // 4. Subtract already-mastered (carries from Class 8-10 foundation!)
  1187→  const { data: mastered } = await supabase
  1188→    .from('learning.progress')
  1189→    .select('concept_id')
  1190→    .eq('user_id', userId)
  1191→    .gte('mastery', 80);
  1192→  const pending = subtractMastered(mergedConcepts, mastered);
  1193→
  1194→  // 5. Add prerequisites recursively
  1195→  const withPrereqs = await addPrerequisites(pending);
  1196→
  1197→  // 6. Sort by chapter order (board curriculum order)
  1198→  const sorted = sortByChapterOrder(withPrereqs);
  1199→
  1200→  // 7. Assemble PRACTICE LAYERS (this is what makes it hybrid):
  1201→  //    For each concept, gather:
  1202→  //    a) Board QNA questions (long-form, short-form, diagram-based)
  1203→  //    b) Entrance MCQ questions (single correct, multiple correct, assertion-reason)
  1204→  //    c) Board PYQs (last 10 years)
  1205→  //    d) Entrance PYQs (NEET/JEE last 10 years)
  1206→  //    e) Speed drill sets (timed MCQ batches)
  1207→  const practiceLayers = await assemblePracticeLayers(sorted, {
  1208→    boardCurriculumId: curriculumId,
  1209→    entranceExamIds,
  1210→  });
  1211→
  1212→  // 8. Schedule daily plan: balance concept learning + board practice + entrance practice + speed
  1213→  const dailyPlan = scheduleHybridDaily(sorted, practiceLayers, userId, entranceExamIds);
  1214→  // e.g., Day plan: 2 new concepts (board+entrance depth) + 1 board QNA practice + 1 NEET MCQ set + 15-min speed drill
  1215→
  1216→  // 9. Cache as learning_path
  1217→  await saveLearningPath(userId, sorted, dailyPlan, practiceLayers, 'hybrid-merge');
  1218→
  1219→  return { concepts: sorted, practiceLayers, dailyPlan };
  1220→}
  1221→```
  1222→
  1223→**Key difference from Depth-Merge:**
  1224→- Depth-Merge (School): only merges DEPTH. One practice format per concept.
  1225→- Hybrid-Merge (Senior): merges DEPTH + PRACTICE FORMATS (board QNA + entrance MCQ) + SPEED DRILLS + BOTH PYQs. Multiple practice layers per concept.
  1226→
  1227→**Daily Plan Structure (Senior Hybrid):**
  1228→```
  1229→Day plan for Class 12 + NEET student:
  1230→  - Learn: Photosynthesis at L4 depth (NEET level)  [30 min]
  1231→  - Board Practice: Write long-form answer on Photosynthesis  [20 min]
  1232→  - NEET Practice: 20 MCQs on Photosynthesis (timed)  [15 min]
  1233→  - Speed Drill: 30 rapid MCQs (mixed topics, timed)  [10 min]
  1234→  - Revision: Spaced repetition items for today  [15 min]
  1235→  Total: ~90 min
  1236→```

  1238→### 8.4 Syllabus-Merge Algorithm (Coaching)
  1239→
  1240→```typescript
  1241→// For student with goals: [RRB Group D, SSC GD, MP Police]
  1242→// Different exams, different syllabi — union them
  1243→
  1244→async function syllabusMergeCombinedCourse(userId: string, examIds: string[]) {
  1245→  // 1. Get all exam_concepts for all selected exams
  1246→  const { data: concepts } = await supabase
  1247→    .from('exams.exam_concepts')
  1248→    .select('concept_id, depth_required, importance, subject, exam_id')
  1249→    .in('exam_id', examIds);
  1250→
  1251→  // 2. Union + dedupe: same concept → take MAX depth + MAX importance
  1252→  const unioned = unionByMaxDepthAndImportance(concepts);
  1253→
  1254→  // 3. Compute overlap stats (for the "72% common" pitch)
  1255→  const overlapStats = computeOverlap(concepts, examIds);
  1256→
  1257→  // 4. Subtract already-mastered
  1258→  const { data: mastered } = await supabase
  1259→    .from('learning.progress')
  1260→    .select('concept_id')
  1261→    .eq('user_id', userId)
  1262→    .gte('mastery', 80);
  1263→  const pending = subtractMastered(unioned, mastered);
  1264→
  1265→  // 5. Add prerequisites recursively
  1266→  const withPrereqs = await addPrerequisites(pending);
  1267→
  1268→  // 6. Topological sort by prerequisite graph
  1269→  const sorted = topologicalSort(withPrereqs);
  1270→
  1271→  // 7. Priority rank: exam_weight × goal_priority × gap × recency × importance
  1272→  const ranked = priorityRank(sorted, userId, examIds);
  1273→
  1274→  // 8. Schedule into daily plan (based on exam dates, available time/day)
  1275→  const dailyPlan = scheduleDaily(ranked, userId, examIds);
  1276→
  1277→  // 9. Cache as learning_path
  1278→  await saveLearningPath(userId, ranked, dailyPlan, overlapStats);
  1279→
  1280→  return { concepts: ranked, dailyPlan, overlapStats };
  1281→}
  1282→```
  1283→
  1284→### 8.5 Priority Score Formula
  1285→
  1286→```
  1287→Priority Score = 
  1288→  (Exam Weight × 0.30) +        // how important is this exam to user
  1289→  (Goal Priority × 0.20) +       // user's priority for this goal
  1290→  (Knowledge Gap × 0.25) +       // how far from mastery
  1291→  (Recency × 0.10) +             // how recently tested in exams
  1292→  (Importance × 0.15)            // concept importance for exam
  1293→```

  1295→### 8.6 "Don't Teach Me Twice" Feature
  1296→
  1297→When a student adds a new goal (exam/class):
  1298→1. System loads the new goal's concepts.
  1299→2. Checks `learning.progress` — which concepts are already mastered?
  1300→3. Skips mastered concepts (or offers a quick diagnostic to verify).
  1301→4. Only adds the DELTA (new concepts + deeper depth for existing).
  1302→5. Updates `learning_paths` with the new combined course.
  1303→
  1304→**Example:**
  1305→- Student mastered "Fundamental Rights" at L2 for SSC.
  1306→- Adds UPSC as a goal → UPSC needs "Fundamental Rights" at L4.
  1307→- System doesn't re-teach L1-L2. It shows: "You know L1-L2. Continue from L3 (Judicial Interpretation) for UPSC."
  1308→
  1309→### 8.7 Daily Plan Auto-Rewiring
  1310→
  1311→Based on exam dates, the plan auto-adjusts:
  1312→```
  1313→180 days to exam → Learning mode (cover syllabus)
  1314→90 days          → Coverage + Practice mode
  1315→60 days          → Practice + Revision mode
  1316→30 days          → Exam mode (mock tests + revision)
  1317→7 days           → Ultra-revision mode (key facts + weak areas)
  1318→1 day            → Light revision (confidence boost)
  1319→```
  1320→
  1321→If exam date changes → plan recomputes automatically.

  1406→
  1407→**AI Doubt Response (in chapter chat):**
  1408→```typescript
  1409→// When a student asks a doubt in a chapter:
  1410→// 1. If a teacher is online → notify teacher, wait for response
  1411→// 2. If no teacher responds within 30s → AI responds
  1412→// 3. AI response is marked as "AI-generated" (transparency)
  1413→// 4. Teacher can later review and add to/correct AI response
  1414→
  1415→async function aiDoubtResponse(roomId: string, doubt: string, conceptId: string) {
  1416→  // Get concept context for AI
  1417→  const concept = await getConcept(conceptId);
  1418→  const prompt = `
  1419→    Student is learning: ${concept.title}
  1420→    Concept summary: ${concept.summary}
  1421→    Student's doubt: ${doubt}
  1422→    
  1423→    Respond helpfully in ${user.preferred_language}. 
  1424→    Be concise. If you don't know, say so.
  1425→  `;
  1426→  const response = await zai.chat.completions.create({ prompt });
  1427→  return saveAndBroadcast(roomId, response, sender_type: 'ai');
  1428→}
  1429→```

  1432→- Knows student's enrolled goals, progress, weak areas.
