   875→     - isDueForReview(nextReviewDate): checks if concept needs review today
   876→     - getReviewUrgency(nextReviewDate): 'overdue' | 'due' | 'soon' | 'future' | 'none'

   880→  2. exam-readiness.ts: Exam Readiness Score
   881→     - computeExamReadiness(userId, examId): fetches exam concepts + progress + cycle date
   882→     - Formula: readiness = (masteryScore × 0.5) + (timeScore × 0.2) + (practiceScore × 0.3)
   883→     - masteryScore: avg mastery of exam concepts
   884→     - timeScore: based on days left (urgent < 7d = 20-70%, 7-30d = 80%, 30-90d = 70%, 90-180d = 60%)
   885→     - practiceScore: attempt coverage (5 per concept = 100%) × 0.5 + accuracy × 0.5
   886→     - Status: not-started / early / on-track / needs-focus / urgent / ready
   887→     - Returns message per exam
   888→  
   889→  3. daily-plan.ts: Personalized Daily Plan
   890→     - generateDailyPlan(userId, availableMinutes=60): generates revision + new learning + practice items
   891→     - Revision: concepts due for review (next_review_date <= today) or needs_revision status
   892→     - New Learning: from learning_paths (combined course) or exam syllabus not yet started
   893→     - Practice: concepts with mastery < 70% and > 0%
   894→     - Time allocation: 30% revision (3 min/item), 40% new (10 min/item), 30% practice (5 min/item)
   895→     - Returns: revision[], newLearning[], practice[], totalItems, estimatedMinutes, summary
