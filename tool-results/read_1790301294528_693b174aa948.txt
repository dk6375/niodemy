    32→    32→## 1. Vision & Philosophy
    33→    33→
    34→    34→### 1.1 The Mission
    35→    35→
    36→    36→> **दुनिया का सबसे best educational platform बनाना — जहाँ कोई भी learner, किसी भी stage पर, किसी भी goal के लिए, सही depth में सीख सके।**
    37→    37→
    38→    38→A unified learning ecosystem where:
    39→    39→- A Class 8 student can prepare for school + Olympiad + NEET Foundation simultaneously.
    40→    40→- A Class 12 student can prepare for boards + NEET/JEE simultaneously.
    41→    41→- A graduate can prepare for multiple competitive exams (RRB + SSC + Police) through ONE combined course — not three separate ones.
    42→    42→- A college student can learn their degree curriculum + placement prep.
    43→    43→- An ITI student can learn their trade + workshop skills.
    44→    44→- Anyone can learn a skill (coding, Excel, digital marketing) anytime.
    45→    45→- Everyone benefits from GK & Current Affairs, personalized to their exam level.
    46→    46→- Books solutions serve as SEO entry points and reference.
    47→    47→
    48→    48→### 1.2 Core Philosophy
    49→    49→
    50→    50→| Principle | Meaning |
    51→    51→|---|---|
    52→    52→| **Knowledge ≠ Curriculum ≠ Exam ≠ Course** | Four separate layers. Knowledge is universal. Curriculum maps knowledge to a class. Exam maps knowledge to a test. Course is a generated path. Never mix them. |
    53→    53→| **W3Schools Model Platform-Wide** | ALL content is freely browsable without login. Enrollment is for structured learning + progress tracking + personalization — NOT for access to content. |
    54→    54→| **One Canonical Entity, Multiple Experiences** | A Concept (e.g., Photosynthesis) is ONE record. It powers: concept page, GK collection, quiz, compare entry, combined course — all from the same data. |
    55→    55→| **Combined Course is the Killer Feature** | Students with multiple goals get ONE optimized path, not multiple separate courses. Two modes: depth-merge (school) + syllabus-merge (coaching). |
    56→    56→| **Don't Teach Me Twice** | If a student mastered a concept for one goal, the system skips it for another goal. Mastery is portable across goals. |
    57→    57→| **AI as Orchestration, Not Authority** | Human experts define canonical knowledge. AI assists with explanations, questions, personalization, tutoring. AI never auto-publishes canonical content. |
    58→    58→| **Mobile-First, Always** | India learns on phones. Every page, every component, every interaction must be designed mobile-first. |
    59→    59→| **Free Forever (For Now)** | All content free. No payment. Enrollment is free. Monetization comes later. |
    60→    60→
    61→    61→### 1.3 What Makes This Next-Gen & Unique
    62→    62→
    63→    63→1. **Combined Course Engine** — No competitor does this. Multiple exams → one optimized path.
    64→    64→2. **Cross-Segment Pathways** — Class 8 → NEET Foundation → NEET → Doctor career. One continuous journey.
    65→    65→3. **Depth-Layered Content** — Same concept taught at different depths based on goal. No duplicate content.
    66→    66→4. **Unified Chat** — One chat system for doubts, AI tutoring, live classes, QNA. Not fragmented.
    67→    67→5. **W3Schools-Style Free Access** — Browse everything free. Enrollment adds structure, not access.
    68→    68→6. **AI Study Companion** — Knows your progress, weak areas, learning style. Personal AI tutor.
    69→    69→7. **Knowledge Graph Navigation** — Visual concept maps, explore by connections.
    70→    70→8. **Exam-Centric GK** — GK personalized to your exam level (RRB basic vs UPSC deep).

   104→   104→### 2.3 Why Supabase Direct (No Prisma)?
   105→   105→
   106→   106→- **RLS (Row Level Security):** Enforce content visibility at DB level. Free users can't access paid content even via API leaks.
   107→   107→- **Supabase Auth:** Built-in, shared across all segments.
   108→   108→- **Supabase Realtime:** Live chat, live class updates, real-time progress.
   109→   109→- **Supabase Storage:** Videos, images, PDFs, PPTs.
   110→   110→- **Edge Functions:** Combined course engine, AI orchestration, spaced repetition — Deno functions.
   111→   111→- **No ORM overhead:** Direct SQL where needed, typed client via `supabase-js`.

   185→   185→### 3.3 Combined Course Applicability (Important)
   186→   186→
   187→   187→Combined course is the killer feature, but NOT every segment needs it. Here's the clear rule:
   188→   188→
   189→   189→| Segment | Combined Course? | Mode | Why / Why Not |
   190→   190→|---|---|---|---|
   191→   191→| **School** | ✅ OPTIONAL | Depth-merge (foundation) + Syllabus-merge (scholarship) | Class 6–10 + NEET Foundation + NTSE share ~same syllabus |
   192→   192→| **Senior** | ✅ OPTIONAL | Hybrid-merge (board + entrance) | Class 11–12 board + NEET/JEE share ~same NCERT |
   193→   193→| **Coaching** | ✅ OPTIONAL | Syllabus-merge (multi-exam) | RRB + SSC + Police — different syllabi, dedupe common |
   194→   194→| **GK** | ✅ Exam-centric personalization | (not "combined course" but personalized per exam) | Same GK, different depth per exam level |
   195→   195→| **College** | ❌ NO | Per-semester path only | Each degree/semester is distinct; no overlap to merge |
   196→   196→| **ITI** | ❌ NO | Trade-based path only | Each trade is distinct; no overlap to merge |
   197→   197→| **Skills** | ❌ NO | Skill tracks / roadmaps only | Each skill is independent; no overlap to merge |
   198→   198→
   199→   199→**Rule:** If a segment's goals share significant syllabus overlap (like School foundation/scholarship, Senior board/entrance, Coaching multi-exam), combined course applies. If goals are disjoint (College semesters, ITI trades, individual skills), no combined course.

   289→   289→## 5. Segments Deep-Dive
   290→   290→
   291→   291→### 5.1 School (Class 6–10)
   292→   292→
   293→   293→**Audience:** Class 6–10 students across boards (CBSE, ICSE, State boards like MP Board).
   294→   294→
   295→   295→**Note on Class 1–5:** Class 1–5 is intentionally excluded from this platform. Young children (ages 6–10) need kids-friendly gamification, animations, voice-led interactions, and a completely different UX paradigm. That is a separate future product, not part of Niodemy.
   296→   296→
   297→   297→**Content Model:**
   298→   298→- Organized by: Board → Class (6–10) → Subject → Chapter → Concept → Lesson
   299→   299→- Each class has its own complete curriculum design (user's specific requirement: "हर class के लिए पूरा system design")
   300→   300→- Board-specific content (CBSE Class 8 Science ≠ MP Board Class 8 Science in structure, though concepts overlap)
   301→   301→
   302→   302→**Goals a student can have (combined course is OPTIONAL):**
   303→   303→- **Basic school study only** — just Class 6–10 board curriculum (no combined course)
   304→   304→- **+ NEET/JEE Foundation** — NCERT taught deeper (depth-merge)
   305→   305→- **+ Scholarship** (NTSE, NMMS, KVPY, Olympiads) — scholarship syllabus ≈ class syllabus (syllabus-merge)
   306→   306→- **+ Any combination** — e.g., Class 8 CBSE + NEET Foundation + NTSE
   307→   307→
   308→   308→**Combined Course Mode (Optional):**
   309→   309→- **Depth-merge** for foundation goals (same NCERT, deeper depth)
   310→   310→- **Syllabus-merge** for scholarship goals (scholarship syllabus ≈ class syllabus, dedupe common concepts)
   311→   311→- Both can combine: Class 8 CBSE + NEET Foundation + NTSE → one optimized path
   312→   312→- User can choose to NOT use combined course — just browse class content sequentially
   313→   313→
   314→   314→**Example:**
   315→   315→```
   316→   316→Student: Class 8 CBSE + NEET Foundation + NTSE Scholarship
   317→   317→
   318→   318→All three map to ~same Class 8 concept set:
   319→   319→  - CBSE Class 8 Science: 40 concepts at depth L2
   320→   320→  - NEET Foundation Class 8: same 40 concepts at depth L3 (+ 5 bridging concepts)
   321→   321→  - NTSE Class 8: same 40 concepts at depth L2 (+ 10 aptitude concepts)
   322→   322→
   323→   323→Combined course:
   324→   324→  - 40 common concepts at depth L3 (max)
   325→   325→  - + 5 NEET bridging concepts at L3
   326→   326→  - + 10 NTSE aptitude concepts at L2
   327→   327→  - Total: 55 concepts, one path, covers all three goals
   328→   328→```
   329→   329→
   330→   330→**Class Transition:**
   331→   331→- When student moves Class 8 → Class 9, system:
   332→   332→  1. Loads Class 9 curriculum
   333→   333→  2. Checks which Class 9 concepts student already mastered (from prior learning)
   334→   334→  3. Skips mastered, focuses on new
   335→   335→  4. "Don't teach me twice" applied across classes
   336→   336→
   337→   337→**Key Principle:** Class 8 content and Class 11 content do NOT merge. Each class is its own bubble. Combined course works WITHIN a class (depth-merge for foundation + syllabus-merge for scholarship), not across classes.
   338→   338→
   339→   339→### 5.2 Senior (Class 11–12 + Entrance Exams)
   340→   340→
   341→   341→**Audience:** Class 11–12 students across streams (Science-Bio, Science-Math, Commerce, Arts) who are ALSO preparing for entrance exams (NEET, JEE Main, JEE Advanced, CUET) alongside their board exams.
   342→   342→
   343→   343→**Why Senior is a separate segment (not part of School):**
   344→   344→Class 11–12 + NEET/JEE is fundamentally different from Class 6–10 + Olympiad:
   345→   345→1. **Dual intense goals:** Board exam (detailed written answers) + Entrance exam (speed MCQs) — both high-stakes.
   346→   346→2. **Same syllabus, different demands:** NEET/JEE syllabus = NCERT Class 11–12 syllabus. Same concepts, but NEET needs DEPTH + SPEED + PYQ practice, while board needs DETAILED QNA + long-form answers.
   347→   347→3. **Different practice modes:** Board = long-answer writing practice; NEET = timed MCQ drills (180 Qs in 180 min).
   348→   348→4. **Foundation → Senior continuity:** Class 8 NEET Foundation student → Class 11 Senior (NEET track). Mastery carries over ("don't teach me twice").
   349→   349→5. **Allen Kota model:** NCERT taught at entrance-exam depth, not separate advanced content.
   350→   350→
   351→   351→**Content Model:**
   352→   352→- Organized by: Board → Class (11/12) → Stream → Subject → Chapter → Concept → Lesson
   353→   353→- Each concept has BOTH board-level depth (L2–L3) AND entrance-level depth (L3–L4)
   354→   354→- Question types for BOTH formats:
   355→   355→  - Board: long-form, short-form, diagram-based, source-based
   356→   356→  - Entrance: MCQ (single correct), MCQ (multiple correct), assertion-reason, numerical, matching
   357→   357→
   358→   358→**Goals a student can have:**
   359→   359→- Class 11/12 board exam (stream-specific)
   360→   360→- NEET (if Science-Bio stream)
   361→   361→- JEE Main / JEE Advanced (if Science-Math stream)
   362→   362→- CUET (for central university admission)
   363→   363→- State CET / other entrance
   364→   364→
   365→   365→**Combined Course Mode: Hybrid-Merge (the third mode)**
   366→   366→
   367→   367→Student: Class 12 CBSE (Science-Bio) + NEET
   368→   368→- **Syllabus:** Same NCERT Biology concepts. NEET may add a few extension concepts.
   369→   369→- **Depth:** max(board_depth, neet_depth) = neet_depth (L3–L4).
   370→   370→- **Practice formats:** Board QNA (long-form) + NEET MCQ (timed) + NEET PYQs + Board PYQs.
   371→   371→- **Speed dimension:** NEET needs 180 questions in 180 minutes → timed speed drills.
   372→   372→- **Result:** ONE combined course that prepares for BOTH board + NEET simultaneously.
   373→   373→
   374→   374→```
   375→   375→Combined Class 12 + NEET course =
   376→   376→  Concepts (depth = NEET level)
   377→   377→  + Board QNA practice (for written exam)
   378→   378→  + NEET MCQ practice (for entrance)
   379→   379→  + NEET PYQs (last 10 years)
   380→   380→  + Board PYQs (last 10 years)
   381→   381→  + Speed drills (timed MCQ sets)
   382→   382→  + Daily plan balancing: concept learning + board practice + NEET practice
   383→   383→```
   384→   384→
   385→   385→**The Pitch:** "आपको board + NEET दोनों की तैयारी एक ही course में। Board के लिए detailed answers, NEET के लिए speed MCQs — सब cover।"
   386→   386→
   387→   387→**Transition: School → Senior:**
   388→   388→- Class 10 student (with NEET Foundation goal) → Class 11 Senior (NEET track)

  1108→  1108→## 8. Combined Course Engine
  1109→  1109→
  1110→  1110→### 8.1 Three Modes
  1111→  1111→
  1112→  1112→| Mode | Segment | What It Does | Example |
  1113→  1113→|---|---|---|---|
  1114→  1114→| **Depth-Merge** | School | Same class, same concepts, deeper depth for foundation goals | Class 8 CBSE + Class 8 NEET Foundation = same NCERT, taught deeper |
  1115→  1115→| **Hybrid-Merge** | Senior | Same syllabus (board + entrance), merge depth + practice formats + speed + PYQs | Class 12 CBSE Bio + NEET = one course, board QNA + NEET MCQ + speed drills |
  1116→  1116→| **Syllabus-Merge** | Coaching | Different exams, different syllabi, union + dedupe | RRB Group D + SSC GD + MP Police = one combined course |
  1117→  1117→
  1118→  1118→### 8.2 Depth-Merge Algorithm (School)
  1119→  1119→
  1120→  1120→```typescript
  1121→  1121→// For student with goals: [Class 8 CBSE, Class 8 NEET Foundation]
  1122→  1122→// Both map to same class level (8), so same concept set, different depths
  1123→  1123→
  1124→  1124→async function depthMergeCombinedCourse(userId: string, goals: Goal[]) {
  1125→  1125→  // 1. Get all curriculum_concepts for all goals (same class)
  1126→  1126→  const curriculumIds = goals.map(g => g.curriculum_id);
  1127→  1127→  const { data: concepts } = await supabase
  1128→  1128→    .from('education.curriculum_concepts')
  1129→  1129→    .select('concept_id, depth_required, importance, chapter_name, order_index')
  1130→  1130→    .in('curriculum_id', curriculumIds);
  1131→  1131→
  1132→  1132→  // 2. Merge: same concept → take MAX depth
  1133→  1133→  const mergedConcepts = mergeByMaxDepth(concepts);
  1134→  1134→
  1135→  1135→  // 3. Subtract already-mastered
  1136→  1136→  const { data: mastered } = await supabase
  1137→  1137→    .from('learning.progress')
  1138→  1138→    .select('concept_id')
  1139→  1139→    .eq('user_id', userId)
  1140→  1140→    .gte('mastery', 80);
  1141→  1141→  const pending = subtractMastered(mergedConcepts, mastered);
  1142→  1142→
  1143→  1143→  // 4. Add prerequisites recursively
  1144→  1144→  const withPrereqs = await addPrerequisites(pending);
  1145→  1145→
  1146→  1146→  // 5. Sort by chapter order (within same class, order matters)
  1147→  1147→  const sorted = sortByChapterOrder(withPrereqs);
  1148→  1148→
  1149→  1149→  // 6. Schedule into daily plan
  1150→  1150→  const dailyPlan = scheduleDaily(sorted, userId);
  1151→  1151→
  1152→  1152→  // 7. Cache as learning_path
  1153→  1153→  await saveLearningPath(userId, sorted, dailyPlan);
  1154→  1154→
  1155→  1155→  return { concepts: sorted, dailyPlan };
  1156→  1156→}
  1157→  1157→```
  1158→  1158→
  1159→  1159→### 8.3 Hybrid-Merge Algorithm (Senior — Class 11–12 + Entrance)
  1160→  1160→
  1161→  1161→```typescript
  1162→  1162→// For student with goals: [Class 12 CBSE Science-Bio, NEET]
  1163→  1163→// Same NCERT syllabus, but NEET needs deeper depth + speed + PYQs
  1164→  1164→// Board needs detailed QNA. Merge ALL practice dimensions.
  1165→  1165→
  1166→  1166→async function hybridMergeCombinedCourse(userId: string, goals: Goal[]) {
  1167→  1167→  const curriculumId = goals.find(g => g.type === 'class')?.curriculum_id;
  1168→  1168→  const entranceExamIds = goals.filter(g => g.type === 'exam').map(g => g.exam_id);
  1169→  1169→
  1170→  1170→  // 1. Get curriculum concepts (board syllabus)
  1171→  1171→  const { data: boardConcepts } = await supabase
  1172→  1172→    .from('education.curriculum_concepts')
  1173→  1173→    .select('concept_id, depth_required, importance, chapter_name, order_index')
  1174→  1174→    .eq('curriculum_id', curriculumId);
  1175→  1175→
  1176→  1176→  // 2. Get entrance exam concepts (NEET/JEE syllabus — mostly same NCERT + extensions)
  1177→  1177→  const { data: entranceConcepts } = await supabase
  1178→  1178→    .from('exams.exam_concepts')
  1179→  1179→    .select('concept_id, depth_required, importance, subject, exam_id')
  1180→  1180→    .in('exam_id', entranceExamIds);
  1181→  1181→
  1182→  1182→  // 3. Merge concepts: union (board ∪ entrance), depth = MAX per concept
  1183→  1183→  const mergedConcepts = mergeByMaxDepthAcrossBoardAndEntrance(boardConcepts, entranceConcepts);
  1184→  1184→  // Result: same NCERT concepts at NEET depth + any extra entrance-only concepts
  1185→  1185→
  1186→  1186→  // 4. Subtract already-mastered (carries from Class 8-10 foundation!)
  1187→  1187→  const { data: mastered } = await supabase
  1188→  1188→    .from('learning.progress')
  1189→  1189→    .select('concept_id')
  1190→  1190→    .eq('user_id', userId)
  1191→  1191→    .gte('mastery', 80);
  1192→  1192→  const pending = subtractMastered(mergedConcepts, mastered);
  1193→  1193→
  1194→  1194→  // 5. Add prerequisites recursively
  1195→  1195→  const withPrereqs = await addPrerequisites(pending);
  1196→  1196→
  1197→  1197→  // 6. Sort by chapter order (board curriculum order)
  1198→  1198→  const sorted = sortByChapterOrder(withPrereqs);
  1199→  1199→
  1200→  1200→  // 7. Assemble PRACTICE LAYERS (this is what makes it hybrid):
  1201→  1201→  //    For each concept, gather:
  1202→  1202→  //    a) Board QNA questions (long-form, short-form, diagram-based)
  1203→  1203→  //    b) Entrance MCQ questions (single correct, multiple correct, assertion-reason)
  1204→  1204→  //    c) Board PYQs (last 10 years)
  1205→  1205→  //    d) Entrance PYQs (NEET/JEE last 10 years)
  1206→  1206→  //    e) Speed drill sets (timed MCQ batches)
  1207→  1207→  const practiceLayers = await assemblePracticeLayers(sorted, {
  1208→  1208→    boardCurriculumId: curriculumId,
  1209→  1209→    entranceExamIds,
  1210→  1210→  });
  1211→  1211→
  1212→  1212→  // 8. Schedule daily plan: balance concept learning + board practice + entrance practice + speed
  1213→  1213→  const dailyPlan = scheduleHybridDaily(sorted, practiceLayers, userId, entranceExamIds);
  1214→  1214→  // e.g., Day plan: 2 new concepts (board+entrance depth) + 1 board QNA practice + 1 NEET MCQ set + 15-min speed drill
  1215→  1215→
  1216→  1216→  // 9. Cache as learning_path
  1217→  1217→  await saveLearningPath(userId, sorted, dailyPlan, practiceLayers, 'hybrid-merge');
  1218→  1218→
  1219→  1219→  return { concepts: sorted, practiceLayers, dailyPlan };
  1220→  1220→}
  1221→  1221→```
  1222→  1222→
  1223→  1223→**Key difference from Depth-Merge:**
  1224→  1224→- Depth-Merge (School): only merges DEPTH. One practice format per concept.
  1225→  1225→- Hybrid-Merge (Senior): merges DEPTH + PRACTICE FORMATS (board QNA + entrance MCQ) + SPEED DRILLS + BOTH PYQs. Multiple practice layers per concept.
  1226→  1226→
  1227→  1227→**Daily Plan Structure (Senior Hybrid):**
  1228→  1228→```
  1229→  1229→Day plan for Class 12 + NEET student:
  1230→  1230→  - Learn: Photosynthesis at L4 depth (NEET level)  [30 min]
  1231→  1231→  - Board Practice: Write long-form answer on Photosynthesis  [20 min]
  1232→  1232→  - NEET Practice: 20 MCQs on Photosynthesis (timed)  [15 min]
  1233→  1233→  - Speed Drill: 30 rapid MCQs (mixed topics, timed)  [10 min]
  1234→  1234→  - Revision: Spaced repetition items for today  [15 min]
  1235→  1235→  Total: ~90 min
  1236→  1236→```
  1237→  1237→
  1238→  1238→### 8.4 Syllabus-Merge Algorithm (Coaching)
  1239→  1239→
  1240→  1240→```typescript
  1241→  1241→// For student with goals: [RRB Group D, SSC GD, MP Police]
  1242→  1242→// Different exams, different syllabi — union them
  1243→  1243→
  1244→  1244→async function syllabusMergeCombinedCourse(userId: string, examIds: string[]) {
  1245→  1245→  // 1. Get all exam_concepts for all selected exams
  1246→  1246→  const { data: concepts } = await supabase
  1247→  1247→    .from('exams.exam_concepts')
  1248→  1248→    .select('concept_id, depth_required, importance, subject, exam_id')
  1249→  1249→    .in('exam_id', examIds);
  1250→  1250→
  1251→  1251→  // 2. Union + dedupe: same concept → take MAX depth + MAX importance
  1252→  1252→  const unioned = unionByMaxDepthAndImportance(concepts);
  1253→  1253→
  1254→  1254→  // 3. Compute overlap stats (for the "72% common" pitch)
  1255→  1255→  const overlapStats = computeOverlap(concepts, examIds);
  1256→  1256→
  1257→  1257→  // 4. Subtract already-mastered
  1258→  1258→  const { data: mastered } = await supabase
  1259→  1259→    .from('learning.progress')
  1260→  1260→    .select('concept_id')
  1261→  1261→    .eq('user_id', userId)
  1262→  1262→    .gte('mastery', 80);
  1263→  1263→  const pending = subtractMastered(unioned, mastered);
  1264→  1264→
  1265→  1265→  // 5. Add prerequisites recursively
  1266→  1266→  const withPrereqs = await addPrerequisites(pending);
  1267→  1267→
  1268→  1268→  // 6. Topological sort by prerequisite graph
  1269→  1269→  const sorted = topologicalSort(withPrereqs);
  1270→  1270→
  1271→  1271→  // 7. Priority rank: exam_weight × goal_priority × gap × recency × importance
  1272→  1272→  const ranked = priorityRank(sorted, userId, examIds);
  1273→  1273→
  1274→  1274→  // 8. Schedule into daily plan (based on exam dates, available time/day)
  1275→  1275→  const dailyPlan = scheduleDaily(ranked, userId, examIds);
  1276→  1276→
  1277→  1277→  // 9. Cache as learning_path
  1278→  1278→  await saveLearningPath(userId, ranked, dailyPlan, overlapStats);
  1279→  1279→
  1280→  1280→  return { concepts: ranked, dailyPlan, overlapStats };
  1281→  1281→}
  1282→  1282→```
  1283→  1283→
  1284→  1284→### 8.5 Priority Score Formula
  1285→  1285→
  1286→  1286→```
  1287→  1287→Priority Score = 
  1288→  1288→  (Exam Weight × 0.30) +        // how important is this exam to user
  1289→  1289→  (Goal Priority × 0.20) +       // user's priority for this goal
  1290→  1290→  (Knowledge Gap × 0.25) +       // how far from mastery
  1291→  1291→  (Recency × 0.10) +             // how recently tested in exams
  1292→  1292→  (Importance × 0.15)            // concept importance for exam
  1293→  1293→```
  1294→  1294→
  1295→  1295→### 8.6 "Don't Teach Me Twice" Feature
  1296→  1296→
  1297→  1297→When a student adds a new goal (exam/class):
  1298→  1298→1. System loads the new goal's concepts.
  1299→  1299→2. Checks `learning.progress` — which concepts are already mastered?
  1300→  1300→3. Skips mastered concepts (or offers a quick diagnostic to verify).
  1301→  1301→4. Only adds the DELTA (new concepts + deeper depth for existing).
  1302→  1302→5. Updates `learning_paths` with the new combined course.
  1303→  1303→
  1304→  1304→**Example:**
  1305→  1305→- Student mastered "Fundamental Rights" at L2 for SSC.
  1306→  1306→- Adds UPSC as a goal → UPSC needs "Fundamental Rights" at L4.
  1307→  1307→- System doesn't re-teach L1-L2. It shows: "You know L1-L2. Continue from L3 (Judicial Interpretation) for UPSC."
  1308→  1308→
  1309→  1309→### 8.7 Daily Plan Auto-Rewiring
  1310→  1310→
  1311→  1311→Based on exam dates, the plan auto-adjusts:
  1312→  1312→```
  1313→  1313→180 days to exam → Learning mode (cover syllabus)
  1314→  1314→90 days          → Coverage + Practice mode
  1315→  1315→60 days          → Practice + Revision mode
  1316→  1316→30 days          → Exam mode (mock tests + revision)
  1317→  1317→7 days           → Ultra-revision mode (key facts + weak areas)
  1318→  1318→1 day            → Light revision (confidence boost)
  1319→  1319→```
  1320→  1320→
  1321→  1321→If exam date changes → plan recomputes automatically.

  1410→  1410→// 1. If a teacher is online → notify teacher, wait for response

  1423→  1423→    Respond helpfully in ${user.preferred_language}. 
  1424→  1424→    Be concise. If you don't know, say so.
  1425→  1425→  `;
  1426→  1426→  const response = await zai.chat.completions.create({ prompt });
  1427→  1427→  return saveAndBroadcast(roomId, response, sender_type: 'ai');
